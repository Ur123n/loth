# 修道院—莱顿大世界移动审验

双击项目根目录 `启动莱顿大世界审验.bat`。需要本机 Godot 4.7.1（启动器使用 `C:\1\Godot_v4.7.1-stable_win64.exe`）。也可在 Godot 中运行 `res://dev/leyton_world_demo/world_demo.tscn`。

出生在艾瑟拉修道院南侧山道，按住 S 向下进入莱顿北门城外；门禁开放时继续向下穿过北门进入贵族区，再到中心广场。地图边缘自动切换，进入后可沿原路返回。

## 路线

- 北线：修道院 ↔ M05 北门城外 ↔ M02 贵族区 ↔ M01 中心广场。
- 西线：M01 ↔ M04 商业区 ↔ M07 西门城外。
- 南线：M01 ↔ M03 贫民窟 ↔ M06 南门城外。
- 东线：M01 ↔ 普通住宅区（抽象路程）↔ M08 东门城外。

九张地图、八条双向连接。东侧住宅区尚无独立地图，其路程用切换提示表达。其他城外出口尚未开放。

## 操作

| 按键 | 行为 |
| --- | --- |
| WASD | 行走 |
| M / Esc | 打开路线图 / 关闭路线图；显示时暂停行走 |
| Tab | 当前地图总览 |
| E | 靠近橙色墙梯点后上下城墙 |
| G | 在城门图循环开放、宵禁、封锁；先离开门洞 |
| C | 切换玩家 / 2×3 格测试车占地；需足够空间 |
| T | 莱顿地表 / 灰盒显示 |
| 0 / 1—8 | 返回修道院 / 跳转八区 |
| R | 当前地图复位 |

## 验收与范围

`tests/map/test_leyton_world_demo.gd` 验证真实输入移动、16 条有向连接的玩家与测试车通行、安全落点、关闭城门阻挡、墙梯和原文件哈希。完整回归入口为 `maps/leyton/tools/validate.ps1`。

`tools/run_capture.ps1` 从当前项目启动隐藏 GPU 实例，输出 `qa/render.json` 和七张 PNG；恢复验收详情见本目录 `WORKLOG.md`。

这是移动审验 Demo，角色和部分城区建筑使用占位形状；地图边缘外可见灰色背景。原视觉审验中的地表噪声、门洞遮挡和道具对比度问题仍待后续美术调整。Demo 不接入存档，不替换生产主场景；修道院与 M05 出口修改只作用于 Demo 实例。
