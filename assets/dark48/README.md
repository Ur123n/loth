本项目**当前生效的美术规格**：俯视 2D · 48×48 像素 · 黑暗奇幻。规格定义见
**[docs/art/style_guide.md](../../docs/art/style_guide.md)**；缺素材按 [docs/art/asset_request.md](../../docs/art/asset_request.md) 提需求。

## 引擎侧使用要点

1. **比例尺 48 px = 1 米**：一张 tile = 1 m²，房间尺寸（米）就是格数；角色精灵 48×96 = 1 格宽 × 2 格高。
2. **显示 1:1**：地图按原始像素显示（不放大），项目已把默认纹理过滤设为 Nearest（像素不糊）。
3. **不要用 `load()` 直接按单文件拼地图**：走管线 —— `maps/godot/tools/build_tileset.gd` 会把本目录的
   单张 PNG 打包成图集（`maps/godot/tilesets/atlas/`）并生成带 `tag`/`solid` 语义与地形集的 TileSet。
4. **自动拼接集的语义**（实测逐字节确认）：文件名 `auto_<补丁>_over_<底材>_<四邻掩码>_v<变体>`，
   图块**属于底材**，掩码表示"这四侧邻格是补丁材质"（`n/e/s/w`）；
   其中 `_none` 与底材地面 tile **完全同图**（`auto_dirt_over_grass_none_v1.png` == `tile_grass.png`）。
   所以：补丁格用普通地面 tile 平铺，紧邻补丁的底材格按掩码选块 —— 边界只画在**底材格内部**，
   相邻两格共享的那条边两侧材质天然一致。
5. **边 tile 不要翻转**：`过渡/` 与 `自动拼接/` 的图块错位翻转会把边界条带翻到错误的一侧。
   破周期感请用**多个变体交替**（每材质 1–3 变体）而不是翻转。
6. **三条色板互不通用**：地图环境用 `色板/map_env.json`，角色用 `色板/char.json`，
   图标/UI/场景用 `色板/souls.json`。别把角色色板拿去画地面。
7. **接地阴影已烘焙进 prop 与角色精灵**（半透明像素）；引擎若再画一层运行时影子会双重投影。
8. 地面**正俯视、无光照方向、无投影**；prop 与角色是**高角度 3/4 俯视 + 左上主光**。

## 已知问题（交付方如实标注，引擎侧先记着）

- `tile_dirt` 自带约 960 个纯白像素 `(234,228,214)`，在暗场里会闪（待美术线修源 tile）。
- 石砖路偏亮（实测 L≈115，是唯一大块亮区），后续焦点光源 prop 上去前建议先压到 L≈92–100。
- 泥土 / 碎石 / 枯草三张中调色相撞在同一色相桶，目前实际是"绿 / 黄褐 / 亮灰"三档可辨。
- 角色正/背向行走只有 2 个可区分相位（侧向 3 个）；两角色精灵明度差约 2 倍。
- 48×48 头像可读性偏弱；自动拼接集与四方向行走帧**只做过数值验收、没做视觉验收**。

详细数值与复核命令见 [交付说明.md](交付说明.md) 第三节，生产线侧规范见 `C:\美术素材制作\docs\04_地图氛围与色板规范.md`。

## 更新素材时

1. 整批替换本目录内容（**过渡 / 自动拼接 / 演示图都是"从已验收地面 tile 合成"的，改一张地面必须整体重做**）。
2. 重跑管线重建图集与 TileSet：
   ```bat
   C:\1\Godot_v4.7.1-stable_win64_console.exe --headless --path C:\游戏 --script maps/godot/tools/build_tileset.gd
   ```
3. 跑校验：`tests\map\test_godot_map_pipeline.gd`。
