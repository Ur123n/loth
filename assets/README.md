# 美术资源（assets/）

本目录存放游戏美术素材与接口约定。素材来自 OpenGameArt（详见 [来源与许可.md](来源与许可.md)）。

> ⚠ **当前美术规格是 48px 黑暗奇幻**：素材在 **[dark48/](dark48/README.md)**（本目录其余 16px 素材属于过渡内容）。
> 规格见 [docs/art/style_guide.md](../docs/art/style_guide.md)。

## 目录结构

- `dark48/`：当前 48px 黑暗奇幻素材，按 Tile、小物件及其他用途组织；规格见 `docs/art/style_guide.md`。
- `buildings/`：大型结构资产包。一座建筑一个目录，包含完整分层视觉、掩码、碰撞、metadata 和独立 Godot Prefab；规范见 `docs/world/building_pipeline.md`。
- `原包下载/`：素材包原始压缩包与完整解压内容（含 Tiled `.tsx`、全部描边风格），是唯一权威副本。`overworld_grass/` 内含修道院扩展（CC0）。
- `hex_切片图格/`：六边形图格切片（平坦/立体/bonus）+ `图格清单.csv`。
- `图格-地面/` `图格-水面/` `图格-道路/` `图格-植被树木/` `图格-围栏篱笆/` `图格-障碍物/` `图格-高地泥泞/` `图格-雪地荒漠/` `其他/`：按用途分类的素材副本，每类附 `说明.md`。
- 未来按模块新增子目录约定：`characters/` `enemies/` `cards/` `equipment/` `terrain/` `maps/` `vfx/` `audio/` `music/`。
- Tiled 地图成品（`.tmx`）统一放在项目根目录 `maps/`（当前为 `maps/Monastery.tmx` 修道院地图），图块集副本在其 `tilesets/` 子目录。

## 资产分类与管线选择

开始制作前必须先分类；像素尺寸大，不等于一定是大型结构，判断依据是它在地图中的复用和逻辑方式。

| 类别 | 典型内容 | 美术交付 | 引擎接入 |
| --- | --- | --- | --- |
| **Tile（图块）** | 地面、道路、岸线、可重复墙段、自动拼接边缘 | 48×48 规则单元或完整拼接集 | 进入 TileSet，由地图编辑器重复铺设 |
| **小物件（Prop）** | 树、石头、箱子、火盆、路牌 | 单张透明 PNG；标明 1×1、2×2 等网格占地 | 作为独立可摆放项进入 TileSet；`solid` 单独声明 |
| **大型结构（Building / Structure）** | 城堡、修道院、要塞、庄园、巨型遗迹 | 先出完整建筑设计，再导出分层透明贴图 | 生成 `assets/buildings/<id>/` 资产包与独立 `.tscn`，最后实例化到地图 |

大型结构不是“大号 Tile”。例如城堡必须先作为一座完整建筑设计，禁止为了铺图方便把最终成图随意切成几十或上百块 Tile。若城墙、塔楼等构件确实需要跨地图重复复用，应把它们另立为一套有明确拼接规则的 Tile 需求，不能拿拆碎的城堡成图冒充通用图块。

尺寸口径分三套并彼此解耦：

- **网格占地**：用 `W×H 格` 表达，决定建筑在地图上占用的地基范围；本项目 1 格 = 48×48 px = 1 米。
- **视觉尺寸**：贴图可以超过网格占地，允许屋檐、塔尖、阴影和装饰越出 footprint；不得用视觉外接矩形反推阻挡范围。
- **碰撞范围**：用独立碰撞掩码/矩形定义，可小于或不同于视觉轮廓；逻辑不读取贴图 alpha 猜碰撞。

大型结构至少分层导出 `base`（地面/墙体主体）与 `roof`（屋顶/前景遮挡）；存在前景、阴影或发光效果时继续拆成独立层。完整生成顺序与资产包结构见 `docs/world/building_pipeline.md`。

## 游戏美术接口约定（数据字段）

所有数据类（角色/卡牌/装备/物品/NPC/道途/buff/敌怪）统一含三个美术字段，均可留空（留空使用色块/文本占位）：

- `icon` —— 图标（列表/槽位小图），res:// 路径
- `art` —— 主体贴图（战斗/详情表现），res:// 路径
- `animation` —— 动画/动画场景资源，res:// 路径
- 角色另有 `portrait`（立绘）。

**卡牌例外**：卡牌 JSON 的 icon/art/animation 为相对 `content/cards/` 的路径，由 CardDB 拼接为 `res://content/cards/<路径>`（兼容旧字段 art_path）；其余库直接填完整 res:// 路径。

加载统一走 `core/art/art_loader.gd`（ArtLoader）：路径为空或资源不存在时返回 null，不报错。

## 使用提示

- 六边形图格：单格 128x128（平坦）/ 128x144（立体），洋红 `#ff00ff` 为透明色；Tiled 项目可直接用 `原包下载/hex_tiles` 内的 `.tsx`。
- 16x16 / Tiny16 为整张图块表，按 16x16 裁切使用。
- 分类目录中的文件是从原包复制的副本，删除不影响 `原包下载/` 原始内容。

## 许可提示

- 六边形包 CC0，可免费商用、无需署名。
- Tiny16 与 16x16 图块集需在游戏致谢中署名；完整署名文本见 [来源与许可.md](来源与许可.md)。

## 缺素材怎么办

不要在项目里随便糊一张看不出风格的图：先在本目录的分类目录与 `原包下载/` 里找，找不到就按
**[docs/art/asset_request.md](../docs/art/asset_request.md)** 填一张素材需求单（写清尺寸/网格/透明底/语义/许可/验收），
填好的需求单存 `docs/art/requests/`。资产分类见该文档第 1 节，Tile / 小物件的规格与接入流程见第 5、8 节；大型结构改走 `docs/world/building_pipeline.md`。
