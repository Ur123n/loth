# 美术资源（assets/）

本目录存放游戏美术素材与接口约定。素材来自 OpenGameArt（详见 [来源与许可.md](来源与许可.md)）。

## 目录结构

- `原包下载/`：素材包原始压缩包与完整解压内容（含 Tiled `.tsx`、全部描边风格），是唯一权威副本。
- `hex_切片图格/`：六边形图格切片（平坦/立体/bonus）+ `图格清单.csv`。
- `图格-地面/` `图格-水面/` `图格-道路/` `图格-植被树木/` `图格-围栏篱笆/` `图格-障碍物/` `图格-高地泥泞/` `图格-雪地荒漠/` `其他/`：按用途分类的素材副本，每类附 `说明.md`。
- 未来按模块新增子目录约定：`characters/` `enemies/` `cards/` `equipment/` `terrain/` `maps/` `vfx/` `audio/` `music/`。

## 游戏美术接口约定（数据字段）

所有数据类（角色/卡牌/装备/物品/NPC/道途/buff/敌怪）统一含三个美术字段，均可留空（留空使用色块/文本占位）：

- `icon` —— 图标（列表/槽位小图），res:// 路径
- `art` —— 主体贴图（战斗/详情表现），res:// 路径
- `animation` —— 动画/动画场景资源，res:// 路径
- 角色另有 `portrait`（立绘）。

**卡牌例外**：卡牌 JSON 的 icon/art/animation 为相对 `content/cards/` 的路径，由 CardDB 拼接为 `res://content/cards/<路径>`（兼容旧字段 art_path）；其余库直接填完整 res:// 路径。

加载统一走 `core/art/art_loader.gd`（ArtLoader）：路径为空或资源不存在时返回 null，不报错。

## 使用提示

- 六边形图格：单格 128x128（平坦）/ 128x144（立体），洋红 `#ff00ff` 为透明色；Tiled 项目可直接用 `原包下载/hex_tiles` 内的 `.tsx`。
- 16x16 / Tiny16 为整张图块表，按 16x16 裁切使用。
- 分类目录中的文件是从原包复制的副本，删除不影响 `原包下载/` 原始内容。

## 许可提示

- 六边形包 CC0，可免费商用、无需署名。
- Tiny16 与 16x16 图块集需在游戏致谢中署名；完整署名文本见 [来源与许可.md](来源与许可.md)。
