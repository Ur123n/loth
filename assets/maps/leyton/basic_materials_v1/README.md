# 莱顿基础灰盒材质 v1

用途：给现有占地区域先补基础表面，完整建筑造型、作物、树木与细节后续制作。类别为 Tile 材质，不是完整 Building 资产包。

四张源图均由内置 image_gen 分别生成，完整提示词在 `prompts.json`，原图在 `source/`。`build_tiles.gd` 仅做最近邻缩放至 48×48 和 map_env 色板映射，保留原图与 SHA256；没有用程序绘制替代模型图案。

| 图块 | 用途 |
| --- | --- |
| roof | 无完整 Prefab 的建筑占地基础暗瓦面 |
| field | 农田、小农地基础耕土 |
| wood | 可穿行的检查点 / 车队占位基础木板地面 |
| soil | 贫民区、牲畜院地、危险区域基础泥地 |

原牧草/果园/菜地占位复用既有草地材质；作物与果树尚未追加。已有完整建筑、桥梁和门楼保留原美术。T 键仍可返回测量灰盒。

`atlas.png` 是四格 48px 图块拼图；`tiles/` 保存单张；`qa/tiling.png` 从左到右为 roof、field、wood、soil 的各 4×4 铺图预览。`manifest.json` 记录平均亮度和边缘 RGB 差。

本轮基础预览接受重复材质，未声明像素级无缝。暗瓦边缘差约 25.39/255，其他约 6.38–9.55/255；完整屋顶、转角、院地过渡仍待后续。角色、城门关闭屏障和审验标记保留诊断外观。

验收：`tests/map/test_basic_materials.gd` 比较八区三种门禁状态下所有格子的通行判定，检查无灰色 Terrain 图块残留、T 切回和共享 TileSet 不被污染。移动 Demo 的 16 条有向连接仍由原测试验证。最终运行记录见 `dev/leyton_world_demo/WORKLOG.md`。
