# 参考图街坊基础素材 v3

内置image_gen生成；参考：项目根目录微信图片_20260928022820_117_6.jpg。prompts.json保存完整提示词，source/保存原图及街屋初稿，manifest.json记录原图/游戏图SHA与裁切尺寸。

- street_row：14×8格共墙街屋；720×576画布，左上视觉偏移(-24,-576)。
- corner_residence：12×9格转角宅邸；624×624画布，偏移(-24,-624)。
- service_wing：5×11格纵深附属翼；288×672画布，偏移(-24,-672)。
- well：2×2格井台FreeProp；144×192画布，偏移(-72,-192)。

三个Pattern场景锚点为占地左下角；井台为占地下缘中心。独立碰撞不从透明贴图推导。各自tscn可复用；样段将完整视觉内部划成屋顶/立面以做遮挡，未切为地面Tile。

注册仅以alpha>=0.05测量外框，再最近邻缩放，保留框内原alpha，不重画生成内容。资产仍为候选，像素簇、投影比例和重复使用需结合样段审验，不把生图成功等同于全城美术完成。
