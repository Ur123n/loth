# 莱顿城地表 v2

## 来源与文件

- 三张源图由内置 image_gen 生成：grass、dirt、road_stone；完整提示词见 `prompts.md`，原图在 `raw/`。
- 使用现有美术工程 pixelize.py 做48px量化，显式 tileable=True；map_env 子集色板保存在 `palette.json`。
- 草地/道路各4种：基础图与3种内部重排派生变体，边缘3px共享，未翻转；不是4张独立生成源图。
- `autotile/`：草→土、土→路，各16配置×2变体；全部从本批新底材派生。
- `shore/`：四邻无岸/草岸/土岸的81组合；沿用v1水纹、v2草土纹理合成。
- 深水与墙顶继续引用surface_v1的已验收图块；其色板/源图/处理器记录保留在v1。
- `manifest.json`：基础图哈希、亮度、像素处理器哈希与580条边缘检查记录。

## 数值与视觉

草地平均亮度46.47，泥土77.23，铺路石98.50。相对旧dark48对应基础图，像素亮度标准差约下降43%/41%/60%；此数值用于说明反差变化，不作为消除重复感的证明。
实际Godot总览和近景已与v1比较：原草丛纹样及道路横带明显减弱。地图仍是地表预览，建筑为占地块。

## 边界

地表过渡不改变逻辑碰撞。湿岸只进入原水格，最多约7px，仍不可行走。四邻过渡保留混合材质交点单个角像素的约定；岸线仍跟随方格几何。立体河岸、桥墩、栏杆、城墙立面与完整建筑属于后续工作。

构建规范：`maps/godot/tilesets/leyton_surface_v2.spec.json`。当前生成TileSet：4来源、156图块、2地形集。v1完全保留。
