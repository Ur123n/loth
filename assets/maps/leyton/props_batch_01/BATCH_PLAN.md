# 莱顿共享物件批次01

用户指定先批量制作美术并验收。本批分类为FreeProp：木箱、木桶、粮袋堆、煤筐、公告栏、空手推车。覆盖市场、粮煤物流、救济、城门登记与公共告示。

使用内置image_gen逐件生成独立透明源图。全部为候选素材，不覆盖旧资源。逻辑48px=1m；正交高角3/4，西北光，窄南立面，无等距菱形、无地板背景。物体小阴影保留，透明画布不决定碰撞。

交付：六张原图、六张规格化PNG、精确提示词、尺寸/接地点/建议占位清单、像素与透明度QA、同场景比例与前后遮挡验收图。

建议画布：木箱/木桶96×96、粮袋/煤筐144×96、公告栏144×144、手推车144×192。画布含留白；实际物体按0.7—2米尺寸注册。将1.8米人体测量线稿放在验收场景作为比例尺（旧角色素材实际人体尺寸不一致）。大画布不代表实际占地。

验收先检查单物体完整轮廓、平行线与材质辨识，再检查缩小尺寸、透明边缘、接地点、背景适配、碰撞建议和排序。用户美术审阅前保持candidate，不整批放入八图。
