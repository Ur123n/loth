# 莱顿城拓扑文件

## 当前版本

- `leyton_master_topology_v01.svg`：严格正交的总拓扑源文件。
- `leyton_master_topology_v01.png`：由 SVG 无透视栅格化的预览图。
- `leyton_master_topology_v01.json`：地图尺寸、画布位置、连接和固定通行约束。

## 比例规则

- 游戏逻辑瓦片：48×48 px。
- 拓扑图换算：1 个游戏瓦片 = 4 个拓扑图像素。
- 地图矩形宽高严格由 `grid_size × 4` 得到，不允许为了排版拉伸。
- 全图使用正交俯视，不使用透视、景深、倾斜相机或近大远小。
- SVG 和 JSON 为比例依据；PNG 只作为预览，禁止从截图反推格数。
