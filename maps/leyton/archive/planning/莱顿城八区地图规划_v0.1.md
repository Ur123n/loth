# 莱顿城八区大地图规划 v0.1

状态：**核心规划与主要视觉方向已落实；可以进入八图灰盒与首批概念设计**  
基础规格：48×48 px 瓦片、俯视 2D、八张独立地图、地图边缘切换。

## 已拍板的核心决策（2026-09-14）

1. 东门与中心广场之间存在普通住宅区，但不单独制作地图；通过场景切换中的抽象路程表现。
2. 莱顿城常住人口约 3,000—5,000 人，属于小型地方城市，而非区域大都会。
3. 四座城门执行日常宵禁，并可在战争、疫病、邪秽、异魔或政治事件中临时封锁。
4. 河流东西贯穿莱顿城，绕开中心广场，并在城西汇入/形成大型灌溉湖。
5. 主焚尸场是城内建筑，不设在城门外。
6. 莱顿城归地方贵族管辖；具体家族与纹章仍待确定。
7. 城墙可登上，门楼、墙梯、巡逻道和城垛需要具备实际通行空间。
8. 最终交付同时包含分层 PNG、地图 JSON 和可运行的 Godot 场景。
9. 城墙统一使用深青色石砖，保留煤烟、潮痕、磨损和修补痕迹作为区域变体。
10. 中心广场核心地标为太阳神像：健硕、肌肉感明确的神祇低头，以悲悯神情俯视世人。
11. 城南贫民窟采用高压迫度表现：大量棚屋密集侵占旧街，空间杂乱、无序、拥挤。
12. 莱顿城领主为罗兰·恩索菲尔德；家徽为银底黑边盾徽，中央是无门黑色方塔，方塔立于三道暗金色麦穗组成的田垄之上，塔顶悬一枚小型银色八芒星。
13. 河流从中心广场南侧绕行；M01 南侧河口与 M04 直连水系统一在纵坐标第64格，北绕方案仅保留为归档对照。

## 一、固定需求

- 城内四图：中心广场、城北贵族住宅区、城南贫民窟、城西商业区。
- 城门与城外四图：北门、南门、西门、东门；每张同时表现城墙、守门卫兵与以耕地为主的城外区域。
- 城门必须贴在城门外地图的“城市侧边缘”，不能放在地图中央。
- 城墙、煤炭配给、粮仓、焚尸制度、城卫巡逻和异质检查必须符合现有世界规则。

## 四、八张地图规划

### M01 中心广场

- 定位：行政、宗教、公告、公共仪式和四区交通核心。
- 构图：十字主路汇入中央石铺广场；视线中心设置太阳神像——健硕、肌肉感明确的神祇低头悲悯地望向世人。神像需兼具宗教象征、城市导航地标与公共仪式背景三项功能。
- 必备建筑：城政厅/领主办事厅、太阳神教大礼堂、城卫值房、公共水井或蓄水池、公告栏。
- 世界功能：煤炭配给公告、失踪人口与焚尸名册、税令、悬赏、节庆与公开审判。
- 河流处理：河道从中心广场南侧绕行，不切开中心广场主体；M01 西侧与 M04 河道在纵坐标第64格对接，东侧经未制图的普通住宅区继续通往 M08。
- NPC：官吏、修士、城卫、请愿者、差役、信使；日常不宜像商业区一样摆满摊位。
- 出口：北接 M02，南接 M03，西接 M04；东侧通过不制图的普通住宅区抽象路程接 M08。

### M02 城北贵族住宅区

- 定位：低密度、高秩序、资源充裕，与南区形成强烈阶层对照。
- 构图：宽直道路、围墙宅邸、内院树木、马车回转场、小型守卫岗亭。
- 必备建筑：2—3 座代表性宅邸、贵族会客所或军官俱乐部、私家马厩、受保护的水源。
- 细节：石材维护较好；煤堆有棚盖和封条；垃圾、积水和裸露污水显著少于南区。
- NPC：贵族、管家、仆役、家庭卫兵、医生、书记员、送货人。
- 出口：南接 M01，北接 M05。

### M03 城南贫民窟

- 定位：人口最密、治安和卫生最差，但不能只画成“坏人区”，应有真实社区生活。
- 构图：采用高视觉压迫度；大量棚屋与违建木屋挤入旧道路，建筑密集叠压、朝向杂乱，形成无序、拥挤的曲折窄巷，并配置共用灶、晾晒绳和破损排水沟。仍需保留少量可辨识的社区生活节点，避免空间完全失去导航性。
- 必备设施：教会施粥点/孤儿救济点、公共水井、廉价旅舍、灰烬收集点、临时尸体登记棚。
- 主焚尸场：作为城内封闭建筑，设在南区靠城墙一侧；包含收尸门、登记间、煤仓、炉房、烟囱、骨灰暂存室与隔离院，和普通住宅保持防火净空。
- 风险点：火灾、疫病、尸体未及时上报、帮派敲诈、夜间邪秽事件。
- NPC：苦工、难民、孤儿、洗衣妇、摊贩、失业老兵、巡逻城卫、基层修女。
- 出口：北接 M01，南接 M06。

### M04 城西商业区

- 定位：城市最繁忙区域，承接西部煤铁与远途商队。
- 构图：东西向车行主街贯穿；摊位、固定店铺、仓库和旅店由中心向西逐渐增多。
- 必备建筑：综合市场、商会或秤量所、煤炭配给仓、铁匠铺、药剂铺、旅店、车马栈。
- 河流与水运：东西向河道穿过或贴近商业区，设置货运石桥、小型卸货埠和水闸；河道继续向西汇入大型灌溉湖。
- 世界功能：煤车查封、皇室军需封条、商税、护商佣兵招募、异质货物检查。
- NPC：商人、工匠、搬运工、税吏、佣兵、城卫、扒手、旅客。
- 出口：东接 M01，西接 M07。

### M05 北门与城外

- 城墙沿地图**南边缘**横贯；北门嵌在南边缘中央，玩家向南穿门进入 M02。
- 城外内容：贵族庄园所属规整大田、果园或牧草地、石砌田界、税粮车道。
- 门防：双层门、门楼、守卫换岗、旅客登记桌、异质探测器；整体秩序最好。
- 城墙玩法：门楼楼梯可登墙，墙顶巡逻道向东西两侧延伸至地图边缘。
- 远端出口：地图北边缘接世界道路。

### M06 南门与城外

- 城墙沿地图**北边缘**横贯；南门嵌在北边缘中央，玩家向北穿门进入 M03。
- 城外内容：密集小块佃田、菜圃、排水沟、牲畜栏、临时难民棚；仍以耕地为主。
- 门防：人流最大、检查最粗暴；可设置廉价劳工集散、伤病隔离棚。
- 城墙玩法：南门楼可登墙；城内焚尸场不放在本图，只可通过城内方向的烟囱轮廓建立视觉联系。
- 远端出口：地图南边缘接世界道路。

### M07 西门与城外

- 城墙沿地图**东边缘**纵向延伸；西门嵌在东边缘中央，玩家向东穿门进入 M04。
- 城外内容：大型灌溉湖是核心地标，周围仍以麦田、灌渠和堤岸农路为主体；另有商队停车场、煤车待检区、车辙深路和修车棚。
- 门防：货物称量、煤炭封条与军需检查最严；步行人流与车流分道。
- 水系：城内河道经商业区穿出城墙水门后汇入灌溉湖；主西门与水门分离，水门设铁栅、检修步道和守卫点。
- 城墙玩法：门楼和邻近水门均有可达墙顶巡逻道。
- 远端出口：地图西边缘接煤铁产区和商路。

### M08 东门与城外

- 城墙沿地图**西边缘**纵向延伸；东门嵌在西边缘中央，玩家向西穿门默认进入 M01。
- 城外内容：谷物与豆类轮作田、磨坊或风车候选点、东部驿道；东西向河流从东侧进入，穿过农田后由独立水门进入城内住宅区。
- 门防：普通旅客与地方信使为主；保留军队快速出城通道。
- 城墙玩法：主门楼与河道水门之间由可行走城墙连接。
- 远端出口：地图东边缘接世界道路；河道继续向东延伸。

## 五、城门外地图通用结构

从“城市侧边缘”向“荒野侧边缘”依次布置：

1. 城墙、门楼与门洞；
2. 守卫检查区、拒马、登记桌、异质探测器；
3. 城墙净空带，禁止永久建筑和高作物；
4. 近郊菜地、粮田、牲畜棚和农舍；
5. 田间支路汇入城门主路；
6. 地图远端转为世界道路，连接后续荒野地图。

四门需要共享相同的墙体规格和门防语言，但通过农田形状、道路用途、守卫强度和附属设施形成差异。

## 六、城市生存设施建议

- **焚尸设施**：已确定为城内建筑，位于城南贫民窟靠城墙一侧。采用封闭院落、专用运尸入口、独立煤仓和高烟囱，并设置防火隔离带。
- **煤炭总仓**：建议在城西商业区靠西门一侧，设皇室封条、专用守卫和防火净空。
- **主粮仓**：建议在西区与中心交界，避免紧贴贫民窟，也不直接暴露在城外。
- **公共水源**：东西向河流绕开中心广场并流向城西灌溉湖；中心、南区和西区仍保留水井，北区拥有独立受保护水源。河水不能直接视为安全饮水。
- **地方统治**：莱顿城由领主罗兰·恩索菲尔德治理；城政厅、税吏和城卫受其控制，皇室只通过煤炭誓约、军需封条与城主任免权体现上级影响。
- **恩索菲尔德家徽**：银底黑边盾徽；中央为没有城门的黑色方塔，立于三道暗金色麦穗构成的田垄之上；塔顶悬一枚小型银色八芒星。家徽用于城政厅、门楼旗帜、城卫盾牌、封蜡、税粮车与官方告示，但不得压过皇室煤炭和军需封条的识别层级。
- **城卫体系**：中心为总值房；四门各有门卫队；北区为高频巡逻，南区为少量高压巡逻，西区侧重税货检查。
- **教会救济**：中心有正式礼堂，南区有基层施粥/收尸点，避免把教会只表现为压迫机构。

## 七、制作顺序

1. 核心八项决策已落实；补定河道绕行侧、所属贵族家族、玩法权重、室内范围和同屏 NPC 等剩余项。
2. 画八图的 1:8 灰盒缩略布局和连接点，不放细节资产。
3. 先制作 M01、M04、M07，验证城市道路、河道、灌溉湖、商业密度、可登城墙与城门比例。
4. 制作 M02/M05 与 M03/M06 两组阶层对照。
5. 最后制作 M08，并统一四门、可登城墙、耕地、河流水门和世界道路接口。
6. 添加 NPC 刷新点、昼夜状态、碰撞、导航、遮挡和切换触发器。
7. 做八图连通、门洞宽度、马车通行、拥堵、越界和性能 QA。

### 最终交付目录约定

每张地图同时交付以下三部分：

- **分层 PNG**：`ground`、`water`、`roads`、`structures`、`roofs`、`props`、`foreground`、`lighting_mask`。
- **地图 JSON**：地图尺寸、48 px 瓦片规格、图层顺序、碰撞、导航、高度、出生点、场景出口、NPC 刷新位、河流/水门、城门状态和宵禁规则。
- **Godot 场景**：每图一个 `.tscn`；使用 TileMap/TileMapLayer、NavigationRegion2D、StaticBody2D、Area2D 场景出口，以及可切换开放/宵禁/封锁状态的城门节点。

Godot 场景必须能直接读取同名 JSON；PNG 与 JSON 仍保持引擎外可复用，避免地图数据只存在于 `.tscn` 中。
