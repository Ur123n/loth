# 莱顿城八区 1:8 灰盒 v0.1

## 比例与用途

- 游戏瓦片：48×48 px。
- 灰盒缩放：1:8，即每个游戏格固定绘制为 6×6 px。
- 投影：严格正交俯视；无透视、无近大远小、无单图拉伸。
- JSON 是格数、占地和出口的坐标依据；PNG 用于构图审阅，不从截图反推坐标。

## 文件

- `leyton_graybox_layouts_v01.json`：九个灰盒布局的整数格数据。
- `render_grayboxes.ps1`：确定性渲染器。
- `leyton_graybox_contact_sheet_v01.png`：九图原生比例总览，不缩放单图。
- `M01_central_square_river_south_graybox_v01.png`：M01 河流南绕候选。
- `M01_central_square_river_north_graybox_v01.png`：M01 河流北绕候选。
- `M02` 至 `M08`：对应城区/城门灰盒。

## 图面约定

- 黄褐色：道路与桥面。
- 蓝色：河道、湖泊和水系。
- 深青色：城墙。
- 深灰及分类色块：建筑或功能占地。
- 绿色边缘短线：场景出口带。
- 细格：1个游戏瓦片；加重格线：8个游戏瓦片。
