# 战斗敌怪贴图美术规范

状态：v1.0，首批七类敌怪、21 张正式资源。本文是 `docs/art/style_guide.md` 的敌怪专项补充；如有冲突，以总风格规范与本文更严格的条款为准。

## 1. 交付范围

首批制作以下七类敌怪：

1. 褴褛骷髅
2. 武装骷髅
3. 野狗
4. 普通猪人
5. 猪人屠夫
6. 猪人斥候
7. 猪人投矛手

每类敌怪必须交付一套三张、透明背景的战斗贴图：

| 状态 | 后缀 | 用途 |
| --- | --- | --- |
| 正面战斗形象 | `_front.png` | 存活时的静态战斗形象 |
| 尸骸 A | `_corpse_a.png` | 第一种死亡落点形态 |
| 尸骸 B | `_corpse_b.png` | 第二种死亡落点形态，减少重复感 |

本批共 **7 × 3 = 21 张正式 PNG**。放大预览、接触表、源图和蒙版属于生产附件，不计入正式资源数。

建议目录与文件名：

```text
assets/dark48/敌怪/
├─ skeleton_tattered/
│  ├─ skeleton_tattered_front.png
│  ├─ skeleton_tattered_corpse_a.png
│  └─ skeleton_tattered_corpse_b.png
├─ skeleton_armed/
├─ wild_dog/
├─ pigman_common/
├─ pigman_butcher/
├─ pigman_scout/
└─ pigman_spearthrower/
```

文件名只使用 ASCII 小写与下划线，不写尺寸和版本号。版本由生产 run 与清单记录。

## 2. 战斗地图与投影口径

### 2.1 六边格

资源用于尖顶朝上的六边形战斗地图。美术按需求口径固定：

- 图格纵向单元高度：**48 px**。
- 六边形逻辑边长：**20 px**。
- 单位逻辑上只占一格；身体、武器可在上方视觉空间越出格面，但接地点不能跨到相邻格中心。
- 图格中心是单位节点；贴图采用**底部中心锚点**，与现有 `CharacterVisual.set_texture()` 的落点方式一致。

> 运行时口径：`HexGrid.DEFAULT_SIDE_LENGTH = 20.0` 是战斗六边格唯一基准；兼容字段 `tile_size` 的语义也是边长/外接圆半径。48 px 是美术纵向单元/画布口径，不能用来替代六边形数学边长。

### 2.2 视角与朝向

“正面”指**面向屏幕下方/玩家的高角度 3/4 俯视战斗形象**，不是平视证件照：

- 能同时读到头顶、肩背顶面、胸腹正面和双脚落点。
- 人形敌怪身体中轴大体竖直，允许按职业轻微前倾或含胸。
- 野狗头朝屏幕下方偏左或偏右约 10–15°，仍须一眼读作正面来袭。
- 主光统一来自西北/左上，阴影朝东南/右下。
- 贴图 1:1 显示，禁止引擎双线性缩放；所有预览只用 Nearest 放大。

## 3. 画布、锚点与占地

同一敌怪的正面、尸骸 A、尸骸 B必须使用相同画布尺寸与锚点：

| 敌怪 | 三张图统一画布 | 正面剪影定位 |
| --- | --- | --- |
| 褴褛骷髅 | 48×64 | 瘦、塌肩、略驼背 |
| 武装骷髅 | 56×68 | 比褴褛型更直立，盾与武器扩大上半身轮廓 |
| 野狗 | 56×48 | 低伏、长身、四足着地 |
| 普通猪人 | 56×68 | 中等壮实，轮廓作为猪人基准 |
| 猪人屠夫 | 64×76 | 最宽最厚，重心低，肩腹形成大块体积 |
| 猪人斥候 | 48×64 | 最窄最高挑，长腿、轻装、前倾 |
| 猪人投矛手 | 64×72 | 肩臂宽，斜向投矛形成职业轮廓 |

统一锚点规则：

- 锚点为画布底边中心 `(W/2, H)`；身体落脚线为 `y = H - 7 ± 1`。
- 烘焙接地阴影位于最下方 6 px 内；不得把角色脚底抬高来迁就画布。
- 正面图除武器外，主体顶部和左右至少留 2 px 透明安全边。
- 接地阴影的横向宽度不得超过该敌怪逻辑落脚宽度；屠夫可以更宽，但不得读成占两格。
- 尸骸保持同一锚点，倒地主体集中在画布下半部，不能漂到画布中央或上沿。
- 尸骸的实体主体建议宽占画布 55–85%、高占 22–42%；正面主体建议高占画布 72–90%。

## 4. 共通风格

- **精细像素风、黑暗奇幻、严肃写实**；禁止 Q 版、卡通大头、明亮冒险风和 3D 渲染感。
- 大色块优先：先读剪影、头胸、武器，再读少量材质细节；禁止把高分辨率噪声直接缩小成满身散点。
- 使用现有 `char` 39 色板作为首批敌怪共享色板。后处理结束后，所有可见 RGB 必须重新吸附到色板。
- 主体使用硬 alpha；只有接地阴影允许半透明，且只能出现在画布底部限定区域。
- 外轮廓使用 1 px 深色描边。轮廓不能吞掉肋骨、獠牙、鬃毛、四肢间隙等身份结构。
- 骨白、獠牙白、金属亮边都是稀有亮色；禁止让整具骨架或整块武器发白发亮。
- 血色只作少量叙事点缀，不得用大片鲜红替代体积与材质塑造。
- 每个敌怪必须在原始 1× 像素尺寸下可辨；不能依赖 4× 预览才看清类别。

## 5. 分型规范

### 5.1 褴褛骷髅 `skeleton_tattered`

定位：最弱、最破败、靠本能扑咬的亡者。

- 剪影：窄肩、塌胸、脊柱弯曲，一侧肩膀明显低于另一侧。
- 身份结构：裸露颅骨、黑眼窝、可读的肋骨笼、细长胫骨。
- 衣着：腐烂裹尸布或残破短袍，只覆盖部分骨架，至少露出头、胸腔和一条小腿。
- 武装：不持正规武器；可有一截碎骨或短木，但不能读成“武装骷髅”。
- 配色：脏骨灰/旧象牙为中亮块，布料与关节缝为深灰褐；骨白高光仅落在额骨、肩峰和胫骨短边。
- 姿势：双手前伸或一手垂落，重心不稳，具有被残魂牵引的僵硬感。
- 禁止：完整盔甲、整洁服装、发光眼睛、笔直军姿、干净雪白骨骼。

尸骸：

- A：侧倒，颅骨仍连着半截脊柱，肋骨笼朝向镜头。
- B：下肢与躯干错开成骨堆，颅骨滚到肩侧，但所有骨块仍形成一个集中落点。

### 5.2 武装骷髅 `skeleton_armed`

定位：保留军人轮廓的有组织亡兵；不是全身密封的铠甲骑士。

- 剪影：站姿比褴褛型直立，左侧残破圆盾、右侧缺口短剑或锈矛形成清晰武装轮廓。
- 身份结构：颅骨与至少一段肋骨必须外露，不能被头盔和胸甲全部遮住。
- 装备：凹陷铁盔、断裂肩甲、腐烂皮带、小圆盾；金属面积不超过主体可见面积约 35%。
- 配色：冷灰铁、暗锈红、骨灰白；盾面以大块深色为主，只在边缘放窄高光。
- 姿势：盾略向前、武器斜下待击，体现纪律残余而非英雄姿态。
- 禁止：崭新整套板甲、巨盾遮住身体、双手巨剑、蓝色魔法火焰。

尸骸：

- A：盾压住部分胸腔，武器脱手落在身体近旁。
- B：向另一侧折倒，断盾或武器横过骨堆；不得只是 A 的水平镜像。

### 5.3 野狗 `wild_dog`

定位：饥饿、低伏、快速的荒野野狗；必须读作狗而不是狼、鬣狗或亡灵兽。

- 剪影：肩高低于猪人腰部，长口鼻、下垂或缺损耳、一条低垂尾巴，四足清晰。
- 体态：瘦削但仍有肌肉，肋部略凹，前肩高、后腰低，正准备扑咬。
- 配色：暗褐、污灰、黑背，口鼻和爪尖少量浅色；眼睛不发光。
- 毛发：以颈背、尾根的几簇硬边表现，禁止全身均匀毛躁噪点。
- 禁止：巨大狼头、蓬松狼尾、斑鬣狗圆耳、裸露内脏、奇幻角或魔法效果。

尸骸：

- A：侧卧伸展，一条前腿弯折，头部贴近前爪。
- B：身体蜷曲，后腿收拢、头朝相反方向；与 A 的外轮廓差异必须明显。

### 5.4 猪人物种锁（四个变体共同遵守）

四个猪人必须看起来属于同一物种、同一巢穴文化。以下结构不可被装备或职业差异覆盖：

- **深色皮肤**：暗褐、煤黑褐或冷灰褐，是四型共同的最大或第二大色块；可见皮肤不得被调成粉红家猪色。
- **背部鬃毛**：从头顶后缘、后颈延伸到肩背的硬质深色鬃脊。正面 3/4 视角下至少要在头顶后方和一侧肩背轮廓读到连续毛脊。
- **突出吻部**：口鼻向前突出，鼻盘宽而暗，不能画成人脸加猪鼻贴片。
- **外露獠牙**：下颌两侧各有一枚向上弯的骨色獠牙；1× 尺寸下两侧至少各保留一块独立亮形，不能被嘴部阴影吞掉。
- **耳朵**：短而尖/缺损，位于头顶两侧，不使用圆润家猪垂耳。
- **手足**：粗指、暗蹄或近似蹄足；禁止正常人类手脚配猪头。
- 共同装备语言：粗制铁、骨钉、绳索、兽皮、污布；不使用制式骑士甲、华丽纹章和洁净布料。

#### 普通猪人 `pigman_common`

- 四型基准体型：中等身高、厚胸、略突腹，既不肥硕也不精瘦。
- 装备：短柄斧或钉头木棒、小块兽皮护胸、腰布。
- 姿势：双脚分开，武器置于身体一侧，正面压迫但不过度夸张。
- 识别重点：猪人完整物种锁 + 最朴素的装备配置。

尸骸 A/B：分别表现仰侧倒与俯侧倒；武器位置不同，鬃脊和吻部仍可辨。

#### 猪人屠夫 `pigman_butcher`

- 体型：本批最壮硕，肩宽约为普通猪人的 1.2–1.3 倍；粗颈、厚臂、沉腹、短腿，重心低。
- 装备：宽刃屠刀或重砍刀、污黑皮围裙、粗皮护腕；武器是单一大形，不堆多把刀。
- 姿势：屠刀斜向下，另一手张开或抓住刀背，体现近距离压制。
- 配色：深皮肤与暗围裙为主体，旧铁刃仅有一条冷亮边，暗血迹面积受控。
- 禁止：单纯把普通猪人等比放大、肥胖喜剧形象、厨师帽、现代屠宰装备。

尸骸 A/B：厚重身体分别向左右塌倒，屠刀必须脱离手部或压在近侧，不得竖立。

#### 猪人斥候 `pigman_scout`

- 体型：四型最精瘦，腰窄、长腿、肩较收，整体宽度约为普通猪人的 0.8–0.85 倍。
- 装备：短刀、小皮包、轻薄肩布；不持盾，不穿重甲。
- 姿势：明显前倾、屈膝，一脚略前，像正在探路或准备侧移。
- 鬃毛：较短但更尖锐，从头顶向后形成速度感；仍必须连续可读。
- 禁止：儿童比例、佝偻成哥布林、用缩小整体尺寸代替“精瘦”。头部尺度应与普通猪人接近。

尸骸 A/B：一版向前扑倒，一版侧翻蜷腿；轻装小物不能散落成大量孤立像素。

#### 猪人投矛手 `pigman_spearthrower`

- 体型：躯干接近普通猪人，但肩、上臂、前臂明显发达；手臂是仅次于吻部和獠牙的职业识别点。
- 装备：一根投矛斜跨画面，背后可带 1–2 根备用短矛；矛杆不能水平贯穿相邻单位视觉中心。
- 姿势：持矛臂抬起或后拉，另一臂向前平衡，胸廓随投掷动作扭转。
- 配色：深皮肤大面积外露，手臂不能被袖甲完全遮挡；矛尖只用少量金属高光。
- 禁止：长枪兵的双手平举姿态、细弱手臂、弓箭、巨型长矛超出安全边。

尸骸 A/B：一版投矛落在身体同侧，一版备用矛束散开但仍紧邻主体；不得让矛杆形成跨格误导线。

## 6. 两种尸骸的统一规则

- 尸骸是死亡后的战术状态，不是单独的概念插画；保留该敌怪最少三个身份锚点。
- A/B 必须改变躯干朝向、肢体折叠和武器落点，禁止仅做水平镜像、平移、换色或局部血迹变化。
- 两版主体像素差异率建议 ≥ 12%，但色板、光向、体型和装备必须一致。
- 尸骸比存活形象平均亮度低 8–18%，主要通过减少高光实现，不能整体乘黑导致色阶塌陷。
- 接地阴影更宽、更浅，仍只位于画布底部；尸骸本体使用硬 alpha。
- 不表现夸张肢解、裸露内脏和大面积鲜血。骷髅允许骨块错位，但不能散落到邻格中心。
- 两种尸骸的选择应由战斗实例的稳定种子决定，不能每次刷新随机跳变。

## 7. 可执行 QA 合约

### 7.1 全资源硬门禁

- 文件格式：RGBA PNG，色彩空间 sRGB，无 ICC 引发的运行时色偏。
- 尺寸：严格等于第 3 节表格；同套三张尺寸一致。
- 透明：四角 alpha=0；主体无半透明边缘。
- 色板：所有 `alpha>0` 像素的 RGB 均属于 `assets/dark48/色板/char.json`。
- 半透明：仅接地阴影可使用；其最上像素不得高于画布高度的 85%。
- 裁切：主体和武器不得触碰上、左、右画布边缘；底边只允许透明或阴影触碰。
- 连通性：正面主体应为一个主连通域，武器必须接手或紧贴身体；尸骸允许少量骨块/装备碎件，但不得存在 1 px 浮点。
- 色阶：正面至少 12 种、至多 32 种可见 RGB；避免二值化和高分辨率噪点化。
- 绿色溢色：非设计区域不得出现明显绿幕残留。

### 7.2 语义门禁

以下除数值检测外必须进入接触表人工复核：

| 类别 | 不可丢失的身份色块/结构 |
| --- | --- |
| 褴褛骷髅 | 颅骨、黑眼窝、肋骨笼、残布、至少一条完整胫骨 |
| 武装骷髅 | 颅骨/肋骨外露、盾、主武器、锈铁与骨色分离 |
| 野狗 | 长口鼻、四足、低垂尾、黑背/暗褐毛块 |
| 全部猪人 | 深色皮肤、背部鬃毛、突出吻部、左右獠牙 |
| 屠夫 | 宽肩厚腹、重屠刀、围裙 |
| 斥候 | 窄腰长腿、前倾、轻装短刀 |
| 投矛手 | 发达双臂、投矛姿态、备用矛束或投掷装备 |

猪人额外检查：

- 可见深色皮肤应形成连续大块，而不是被衣甲切成零散像素。
- 鬃毛必须改变头顶/后颈剪影，不能只靠内部颜色暗示。
- 两枚獠牙在 1×、2×接触表上均可分别指出；若量化后合并成一块嘴部高光则判失败。
- 四型叠加剪影后，屠夫最宽、斥候最窄、投矛手臂展最大、普通型居中；排序错误则判失败。

### 7.3 批次审阅表

每次生产必须输出：

1. 21 张资源的统一接触表，按“正面 / 尸骸 A / 尸骸 B”三列排版。
2. 七张正面剪影纯黑对照表，用于检查体型和职业区分。
3. 四个猪人的同尺度叠加/并排表，用于检查物种一致性与体型排序。
4. 1× 原尺寸、4× Nearest 两档预览；审批不能只看放大图。
5. 逐文件 SHA-256、色板命中、alpha、包围盒、连通域和语义色块报告。

## 8. 生成与后处理约束

- 先建立每个物种的正面锚图，再派生同物种职业变体和尸骸；不得七类敌怪完全独立生成。
- 猪人建议先批准普通猪人作为物种锚，再以同一参考图派生屠夫、斥候和投矛手。
- 尸骸必须以已批准正面图为参考编辑，不能重新文生图后靠提示词猜装备。
- 高分辨率候选先抠底，再按目标画布比例缩放；量化前保存身份蒙版，避免深色皮肤/鬃毛与近黑背景合并后被删除。
- 下采样后执行共享色板量化、身份色块保护、碎片清理、1 px 描边和接地阴影，最后再次吸附色板。
- provider 不能直接写游戏目录。候选必须进入 `agent_assets.py` 的 capture → QA → approve → publish 流程。

## 9. 引擎接入状态与剩余内容工作
