# 美术风格与设定规格（俯视 2D · 48×48 像素 · 黑暗奇幻）

**本文是本项目美术的唯一规格**：新素材、新地图、新角色都按这里做；与它冲突的旧素材属于待替换的过渡内容。
素材入库位置见 [assets/dark48/README.md](../../assets/dark48/README.md)，缺素材按 [asset_request.md](asset_request.md) 提需求，
地图编辑见[map_pipeline.md](../world/map_pipeline.md)，建筑材质制作统一见[新版手册](../world/map_production_workflow.md)。

敌怪的战斗正面图、两种尸骸、六边格锚点与首批七类分型要求见 [enemy_sprite_spec.md](enemy_sprite_spec.md)。

规格来源：设定集（`docs/story/setting/整理副本/02_设定集_整理版.md`）定世界观与气质，
美术生产线的[新版配套规范](C:/美术素材制作/docs/美术与内容规范.md)保留风格与内容要求，
游戏侧（本文件）把它们固化成引擎可执行的约定。

## 一、定位

| 维度 | 定义 |
| --- | --- |
| 类型 | **2D 俯视角精细像素风**，图块 **48×48** |
| 气质 | **黑暗奇幻 · 严肃**：衰败、压抑、有重量。不是"活泼冒险" |
| 时代参照 | 中世纪：石砌、木构、铁艺、泥路、边境修道院与废墟 |
| 世界观锚点 | 冥界闭锁、月已暗淡成印记 → **夜与室内几乎无冷光**；死亡不熄 → **焚烧尸体是刚需，火是唯一稳定的暖色光源**；太阳神教边境修道院（收尸、施粥、育婴、被默许持械） |
| 禁忌 | 明亮饱和；青翠茂盛的绿；卡通 Q 版；光滑渐变；3D 渲染感；均匀撒亮的"金箔碎点" |

**核心构图原则**：画面**大部分面积是暗的**；亮色是稀有资源，只用在极少数"叙事焦点"上
（一簇余烬、一线冷光、一块被照亮的石面）。

## 二、尺寸与比例尺

**48 像素 = 1 米**，所以**一张 48×48 图块 = 1 m²**，房间尺寸（米）直接就是格数。

| 用途 | 尺寸 | 说明 |
| --- | --- | --- |
| 地面 / 道路图块 | **48×48** | 四边无缝，满幅材质；项目里 5 张：草 / 枯草 / 泥土 / 碎石泥地 / 石砖路 |
| 地形过渡 / 自动拼接 | **48×48** | 4 组材质对 × 16 配置 × 2 变体（拼接集的语义见第七节） |
| 单格道具 | **48×48** | 枯树、岩石；透明底 + 1px 描边 + **接地阴影已烘焙** |
| 多格道具 | **96×96（2×2）** | 大树、立石；Godot 里按 2×2 网格单元的大图块导入 |
| 角色精灵 | **48×96（1 格宽 × 2 格高）** | 4 方向 × 4 帧行走；**四帧共用同一条地面线（y=89）**，底边对齐格子下沿 |
| 对话立绘 | **96×128** | 不抠底 |
| UI 头像 | **48×48** | 抠底 + 描边 |
| 角色展示卡 | **144×216** | 带背景 |
| 道具图标 | **64×64** | 抠底 + 1px 描边 |
| UI 元素 | 48×48 / 64×32 / 96×64 | 面板 / 按钮 / 角饰 / 符文徽章 |
| 场景概念图 | 384×216 | 不抠底 |
| 墙体构件（规划中） | 墙顶 **48×48** + 朝南立面 **48×24** | 俯视角用"墙顶 + 朝下一条立面"暗示体积；24px ≈ 0.5 m 可视高度 |

> 俯视角的取舍：从正上方看不到墙高。**只给朝南的一面补立面**（光照约定：主光来自西北/左上）。

## 三、量化氛围：75 / 20 / 5

美术要求"整体暗一点"无法验收，规范把它翻译成**可测量的像素面积分布**：

| 光度带 | 亮度 `L = 0.299R + 0.587G + 0.114B` | 目标占比 | 内容 |
| --- | --- | --- | --- |
| 深色 dark | `L < 90` | **75%** | 黑、灰、暗黄、暗橄榄、棕 —— 画面主体面积 |
| 浅色 light | `90 ≤ L < 185` | **20%** | 陈旧土黄、灰石、亚麻色 |
| 亮色 accent | `L ≥ 185` | **5%** | 暗金、烬黄、骨白、高光白 —— **高对比点缀** |

**这条规则怎么用（重要）**：75/20/5 是**画面级**指标，由**铺图材质配比**实现，
**不能逐件套用**（早期逐件强制同一分布，导致五种地形平均明度只差 1–4，评审判词是"路不是路"）。

- **素材级**只管两件事：各自的**平均亮度**（按材质家族拉开阶梯）+ **中调色相**（材质可辨），并限制亮色配额。
- **画面级** 75/20/5 由标定配比兑现：**草 60% + 枯草 15% + 泥土 12% + 碎石 6% + 石砖路 7%**
  （实测 → 深 76.3 / 浅 23.2 / 亮 0.5）。
- **亮色的 5% 缺口是有意留的**：地面保持干净，5% 亮色将来集中到 2–3 个焦点物体（火堆/火盆/金属反光/水面），
  而不是均匀撒在地面。

**引擎侧实测**：本项目 48px 示例地图 `maps/godot/scenes/abbey_outskirts.tscn` 合成预览实测
**深 74.4% / 浅 25.2% / 亮 0.4%**（`maps/godot/tools/preview_map.gd` 会打印 COMPOSITION），
即：**地图只要按上面的配比铺，画面级氛围自动达标**。

## 四、色板：三条互不通用的线

| 色板 | 用在哪 | 色数 |
| --- | --- | --- |
| `assets/dark48/色板/map_env.json` | **地图地形 / 道具 / 过渡 / 拼接集** | 32（18 深 / 10 浅 / 4 亮） |
| `assets/dark48/色板/char.json` | **两个角色的全部形态与动画** | 39 |
| `assets/dark48/色板/souls.json` | **道具图标 / UI / 场景概念图** | 24 |

- 除描边色 `(12,10,16)` 外，所有像素颜色都能在对应色板里找到；描边色要并进色板才能 100% 归零。
- **不要把角色色板拿去画地面**：`souls` 是冷蓝灰金属体系（为盔甲武器设计），放到地图环境上深色不够、亮色超标近 3 倍，
  深色带 84.5% 是越界冷色相 —— 与"黑灰暗黄"的要求相反。
- 深色带刻意留 20 档：避免"暗成一片死黑"；亮色只 3 档且都"脏"（旧金、骨色），**天然稀缺才能当点缀**。

## 五、视角与光照（地板与立件的规则不同）

| 对象 | 视角 | 光 | 描边/落地 |
| --- | --- | --- | --- |
| **地面 / 道路 / 过渡图块** | **正俯视正交**（正上方垂直向下看） | 平坦环境光，仅缝隙内极轻微压暗；**无方向性主光、无投影** | 满幅材质，不抠底不描边 |
| **道具（树石）/ 角色** | **高角度 3/4 俯视** | **左上（西北）单一主光** | 抠底 + **1px 描边** + **接地阴影烘焙进 PNG**（半透明像素） |

- 地面材质**不能沿用"孤立物体"的提示词**：要"满幅材质、无物体、无地平线、无光照方向、无边框"。
- 接地阴影已烘焙时，引擎**不要再画一层运行时影子**（会双重投影）。
- 只给墙的**朝南面**补 24px 立面，其他三面只留墙顶。

### 统一投影契约：`orthogonal_3q_48_v1`

这里不是纯俯视与等距视角混用，而是一套固定的混合投影：**逻辑地表保持正交方格，立起来的对象使用高角度 3/4 视觉**。
地图、建筑资产和查验工具都应声明同一个 `projection_id = "orthogonal_3q_48_v1"`。

| 项目 | 契约 |
| --- | --- |
| 逻辑网格 | 正方形正交网格，48×48 px = 1×1 m；不旋转、不压成菱形 |
| 地面 | 正俯视；靠道路边界、材质变化表达平面关系 |
| 立件 | 高角度 3/4；只显示朝南立面，角色脚点/建筑接地点作为节点坐标参与 Y 排序 |
| 光照 | 西北主光；朝东南投接地阴影，地面图块自身仍无方向投影 |
| 大型建筑 | 源美术仍是完整 PNG；运行时可按遮挡带分段绘制，但不得拆成地图 Tile |
| 屋顶 | 独立覆盖层；角色进入 `occlusion` 区时淡出或隐藏，不能与 Base 烘成一张 |

大型建筑的“高角度 3/4”必须是**正交斜投影（parallel oblique）**，不是透视相机：禁止消失点、近大远小和广角畸变。南北墙在画面中等宽，东西/南北方向的边各自保持平行；同规格的窗、拱、柱、塔在画布任何位置都保持同一像素尺度，矩形中庭不得画成梯形。体积只靠窄朝南立面、屋顶面和西北光照表达。

视觉能否“嵌进地图”主要靠三件事：墙脚/台坎的朝南立面、统一接地阴影、角色与建筑遮挡带处在**同一个 YSort 容器且同一 z_index**。
单纯把 TileSet 改成 isometric，或把地图整体旋转 45°，都会破坏 48 px = 1 m 的坐标、碰撞和现有素材，禁止这样修。

## 六、材质家族的纪律（可辨性靠这两条）

**明度阶梯**（平均亮度，实测值）：草 **47.5** → 枯草 **61.8** → 泥土 **82.9** → 碎石 **86.9** → 石砖路 **115.1**。
家族间距：草↔土≈26、土↔路≈32、草↔路≈68。**"石砖路"是画面唯一的大块亮区，玩家靠明度就能一眼认出可走区域。**

**中调色相**（只靠明度不够，必须分家）：

| 家族 | 目标色相 | 饱和度处理 |
| --- | --- | --- |
| 草 | 95° 绿 | ×1.7，下限 0.30 |
| 枯草 | 45° 黄 | ×1.5，下限 0.28 |
| 泥土 | 24° 红棕 | ×1.7，下限 0.32 |
| 碎石土 | 30° 暗黄（低饱和） | ×1.2，下限 0.16 |
| 石砖路 | 215° 冷灰 | ×0.6，下限 0.06 |

> 新做材质时：**先定它落在阶梯的哪一档、属于哪个色相家族**，再动手画。两张材质"只差明度 5"在噪声尺度内，
> 等于没分开（这正是当前泥土/碎石/枯草三张的老问题）。

## 七、地形自动拼接（16 配置）

每张地面材质**四边必须无缝**（边缘逐像素对齐：`f[:,0] == f[:,-1]`、首末行相同）。
破重复感靠**多变体交替**，不靠翻转。

**自动拼接集的语义**（已逐字节实测确认）：

```
auto_<补丁材质>_over_<底材材质>_<四邻掩码>_v<变体>.png
```

- 图块**属于底材**；掩码 `n/e/s/w` 表示"这一侧的邻格是补丁材质"，`_none` 表示四邻都不是补丁 ——
  而 `_none` 与底材地面图块**完全同图**（`auto_dirt_over_grass_none_v1.png` == `tile_grass.png`）。
- 所以：**补丁格用普通地面图块平铺**；紧邻补丁的底材格按掩码选块 → 边界只画在底材格内部，
  "相邻两格共享的那条边两侧材质天然一致" ⇒ 拼接必然连续。
- 四组材质对（底材 → 补丁）：**草地→泥土**、**草地→枯草**、**泥土→石砖路**、**泥土→碎石**。
  注意石砖路与碎石的底材是**泥土**，它们不该直接贴着草地（会留下无人负责的硬边）。
- **边 tile 不许翻转**（错位翻转会把边界条带翻到错误的一侧）；变体只能整张替换。
- 角像素的对角歧义是 16 配置集的固有特性（要完全消除需 47 配置集），实测偏差限制在单角像素内。

## 九、引擎侧落地

1. **1:1 显示**：48px 素材按原始像素显示，不放大（地图 `display_scale = 1.0`）。
   项目已把默认纹理过滤设为 **Nearest**（`project.godot`：`textures/canvas_textures/default_texture_filter=0`）。
2. **图块集由管线生成**：`maps/godot/tools/build_tileset.gd` 把 `assets/dark48/` 的单张 PNG 打包成图集
   （`maps/godot/tilesets/atlas/`），并写入两块引擎要用的数据：
   - 每块图块的**自定义数据**：`solid`（是否阻挡）+ `tag`（语义）；
   - TileSet 的 **`pipeline` 元数据**：材料 → 图块坐标、4 组自动拼接集的掩码 → 变体表；
   - **Godot 地形集**（4 个，四边匹配模式）：在 TileMap 面板用「地形」模式刷，引擎自动选边缘块。
3. **通行性**：`core/world/map_scene.gd` 的 `is_walkable()` 按上面两块数据判定（含 2×2 大图块的 4 格占用）；
   地图上没铺地面的格子视为不可通行。
4. **地图尺寸**：1280×720 视口按 1:1 放**26×15 格**（1248×720）。
   更大的地图需要摄像机跟随（`CameraCtrl` 已具备跟随能力，接进 `main.gd` 是后续工作）。

| 指标 | 判据 | 当前实测 |

## 十一、当前缺口（下一步的美术需求）

按优先级（提需求时直接用 [asset_request.md](asset_request.md) 的模板）：

1. **焦点光源 prop**（火堆 / 火盆 / 烛台 / 金属反光件）—— 补足 5% 亮色，这是"氛围兑现"的最后一块。
2. **垂直面与建筑构件**：崖壁 / 石墙（墙顶 + 朝南立面 48×24）/ 台阶 / 水 / 桥 / 门 / 栅栏
   （修道院整套在 `C:\美术素材制作\docs\07_修道院贴图规范.md` 里已排好米数表：80 m × 60 m）。
3. **地面变体从 1–2 个扩到 4–6 个** + 拼装随机化（现在同一张草地会原样复读）。
4. **三种"土系"材质色相彻底分开**（碎石→真中性灰、泥土→更红、枯草→纯黄）—— 见第六节。
5. **压暗石砖路**（实测 L≈115，是唯一大块亮区；建议压到 L≈92–100 并加暗缝污渍），否则焦点光源上去会赢不了。
6. **清掉 `tile_dirt` 的 960 个纯白像素** `(234,228,214)`：在暗场里会闪。
7. **敌人 / NPC / 更多角色的精灵与动画**（目前只有艾莉丝、鲍德温两人）。
8. 头像可读性（48×48 仍是弱项）；角色正/背向行走只有 2 个可区分相位（侧向 3 个）。
