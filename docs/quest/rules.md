# Quest 规则（规划）

任务系统负责：任务状态、任务条件、任务奖励、任务阶段、任务完成/失败。

## 设计约束

- 任务具体内容存放在 content/quests/（数据驱动），不硬编码在 core/quest/。
- 优先使用已有 条件 / Flag / 奖励 / 对话节点 组合实现任务；不为单个任务创造新机制。
- 任务状态由 QuestSystem 统一管理，存档经 SaveSystem（GameState）持久化。
- 任务奖励可指向：物品/装备/卡牌/经验/钱币/剧情 Flag/世界状态。

## 状态机

```
未接取 → 进行中（阶段 n）→ 已完成 / 已失败
                ↘ 已放弃（可选）
```

- 阶段推进：满足任务条件（对话、战斗胜利、收集、到达地点）时推进。
- 战斗任务：通过 BattleResult 判定胜负，QuestSystem 消费结果推进阶段。
