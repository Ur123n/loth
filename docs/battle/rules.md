# Battle 规则

指定单位为目标的卡牌必须有合法目标才能支付费用。射程同时检查 `min_range` 与 `range`（六边格距离）；旧牌未声明 `min_range` 时默认最小距离 1。

## 1. 战斗流程

1. 进入战斗：从大世界触发点或 Demo 启动器进入 `world/encounters/BattleMap.tscn`。
2. 生成地图与敌怪（正式模式按场景配置；Demo 模式随机生成）。
3. 回合循环：按敏捷（agility）决定行动顺序；玩家行动阶段可移动/出牌/结束回合，之后是敌怪行动。
4. 结算：全灭敌方胜利，全灭我方失败。

## 2. 移动与距离

- 六边形网格（`core/grid/hex_grid.gd`）采用尖顶朝上、odd-r 偏移坐标；相邻格距离为 1。
- 战斗六边格的唯一几何基准是**边长 20 px**。代码中的兼容字段 `tile_size` 表示边长/外接圆半径，不表示贴图画布高度。
- 由此相邻同行格中心横距为 `sqrt(3) × 20 ≈ 34.64 px`，相邻行中心纵距为 `1.5 × 20 = 30 px`。敌怪 48–76 px 高画布可以越出格面，但脚点仍对齐格心。
- 单位每回合有移动力（move_points）；移动不能穿过障碍格。
- 攻击范围以六边形距离计算。

## 3. 伤害、格挡与生命

- **伤害分类**：
  - **受到伤害**：有伤害来源，受力量/虚弱/易伤影响，可被格挡抵消。
  - **失去生命**：无伤害来源，无视格挡，不受力量/易伤影响（如中毒）。
- **格挡**：护盾与格挡统一为单一“格挡”值，回合开始时清空，先于生命抵消受到伤害。
- 玩家对敌怪伤害向上取整、敌怪对玩家向下取整（面板 x 基数 / 100）。
- **统一死亡状态**：任何战斗单位（玩家或敌怪）生命首次归零后原地转为尸骸，退出行动、目标与存活判定；尸骸生命为原最大生命的 1/3（向下取整，至少 1），再次归零才从图格移除。
- 尸骸优先从 `corpse_art_a` / `corpse_art_b` 中按单位稳定种子选图；没有可用贴图时显示独立的尸骸占位形态。禁止把存活贴图整体染灰冒充尸骸。

## 4. buff 规则

| buff | 阵营 | 类型 | 触发时机 | 触发后 |
| --- | --- | --- | --- | --- |
| 易伤 | 负面 | 层数持续 | 受到攻击时 | 不消失 |
| 虚弱 | 负面 | 层数持续 | 造成攻击伤害时 | 不消失 |
| 中毒 | 负面 | 层数增益＋层数持续 | 结束回合时 | 不消失 |
| 预抽牌 | 正面 | 层数增益 | 下回合抽牌时 | 消失 |
| 费用预支 | 正面 | 层数增益 | 下回合获得费用时 | 消失 |
| 疗愈 | 正面 | 层数增益 | 结束回合时 | 每次先按当前层数回复生命，再减一层，耗尽消失 |
| 预格挡 | 正面 | 层数增益 | 下回合开始时 | 消失 |

- 层数持续型 buff 首次施加时，持续时间按层数扩展（中毒 3 层 → 3 回合）。
- 叠层无上限。
- buff 具体数据在 content/buffs/*.json，由 BuffDB 加载。
- `decay_after_trigger` 状态在自己的触发时机先以当前层数结算，再将层数与持续时间各减去 `decay_amount`，层数耗尽即移除；该状态不在行动开始时预先衰减。中毒采用这一规则，所以 3 层中毒在连续三次结束回合时依次失去 3、2、1 点生命。
- 疗愈采用同一触发后衰减规则，上限为 7 层；超过上限的叠加量不生效，回合结束依次回复当前层数的生命。
- **统一结算**：触发时机由 EffectSystem 按 `trigger_timing` 统一结算——
  回合类时机（回合开始 / 结束回合 / 行动阶段 / 抽牌 / 费用）触发一次性效果；
  攻击类时机（受到攻击时 / 造成攻击伤害时）作为**伤害修正钩子**，在
  `take_damage`（易伤 +50%，格挡结算前）/ `resolve_attack`（虚弱 -25%，被动修正前）
  中按层结算，不消耗层数。各 buff 的触发行为按名称注册为函数
  （EffectSystem 的 buff 行为注册表），新增 buff 在注册表登记对应函数即可接入统一结算。

## 5. 敌怪数据字段（content/enemies/*.json）

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 唯一标识 / 名称 |
| `hp_min` / `hp_max` | 生命范围（进入战斗随机） |
| `attack_min` / `attack_max` | 攻击伤害范围 |
| `attack_range` | 攻击距离（六边形） |
| `move_points` | 移动力 |
| `agility` | 敏捷（行动顺序） |
| `ai` | AI 模式：无 / 靠近 / 远离 |
| `archetype` | 行为模板：士兵/狂战士/猎人/护卫/刺客/鲁莽/首领/支援/木桩（空则按小队角色推导） |
| `coin_min` / `coin_max` | 钱币掉落范围 |
| `exp` | 战斗经验（全队共享） |
| `loot_table` | 战利品表：`[{"item":物品名,"chance":百分比,"count":数量}]` |
| `tier` | 难度：普通 / 精英 / Boss |
| `color` | 表现占位色 |
| `description` | 描述 |
| `icon` / `art` / `animation` | 美术接口（res:// 路径，可空） |
| `corpse_art_a` / `corpse_art_b` | 两种尸骸主体贴图（res:// 路径，可空；按稳定种子选择） |

## 6. 敌方小队（content/encounters/enemy_packs.json）

- 每支小队 3~4 只相互配合的敌怪，按强度分类（普通/精英/Boss）。
- 成员带小队角色：前排 / 近战 / 远程 / 护卫 / 侧翼 / 炮灰 / 首领。
- 战斗时按强度随机抽取小队（EnemyPackDB）。

## 7. 胜负与战利品

- 胜利：获得钱币 / 经验（全队共享）/ 战利品表掷骰 / 卡牌奖励（Demo 模式用 content/cards/card_drops.json）。
- 胜负只统计非尸骸、未移除且生命大于 0 的单位；尸骸保留的可破坏生命不算作存活。
- 战斗结束返回 BattleResult 给上层系统（大世界或 Demo 营地），不直接修改剧情/世界状态。

## 8. 敌怪 AI（行为模板 + 评分）

敌怪不拥有玩家式卡组；AI 在有限行为中选择（攻击 / 接近 / 追击 / 撤退 / 保护 / 支援 / 等待；使用技能为 SkillSet 预留）。

| 模板 | 性格 | 行为特征 |
| --- | --- | --- |
| 士兵 | 均衡（进攻 60 / 谨慎 40） | 集火低生命，贴身输出 |
| 狂战士 | 进攻 90 / 谨慎 10 | 集火低生命，追击，永不撤退 |
| 鲁莽 | 进攻 95 / 谨慎 5 | 直奔最弱，无视危险，永不撤退 |
| 猎人 | 进攻 55 / 谨慎 65 | 保持射程边缘，被贴脸先拉开，优先低生命 |
| 刺客 | 进攻 75 / 谨慎 45 | 猎杀高威胁/孤立目标，保持 2 格 |
| 护卫 | 保护欲 90 | 守护本队首领，攻击靠近首领的玩家，不离开首领 |
| 支援 | 保护欲 90 | 贴近受伤友军（治疗技能为 SkillSet 预留） |
| 首领 | 进攻 95 / 谨慎 5 | 高威胁/低生命双优先，不撤退；半血进入狂暴（评分 +20） |
| 木桩 | 无 | 不行动 |

- **目标评分** = 威胁（30 + 力量×2 + 敏捷 + 意志）+ 生命/距离/孤立修正 + 可击杀加成（+50）。
- **行动评分**：攻击 / 接近 / 追击 / 撤退 / 保护 / 等待各按性格加权，取最高分执行；可解释的“犯错”（如猎人放弃击杀拉开距离、狂战士无视危险追击）由评分自然产生。
- **位置评价**：在移动力内选最接近“期望站位”的可达格，谨慎型回避玩家相邻格。
- **调试**：战斗中 F4 或点击敌怪可查看其最近一次决策的目标、候选评分与原因。
