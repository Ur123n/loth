## 2026-08-12　新 buff 系统 + 战斗数据分类 + 格挡统一

### 任务
- 制作 4 个新 buff：预抽牌 / 费用预支 / 疗愈 / 预格挡。
- 分类战斗数据：失去生命（无伤害来源）与受到伤害（有伤害来源）。
- 将护盾与格挡统一为单一格挡值。

### 新 buff 规则（x = buff 层数，如无另行说明）
| buff | 触发时机 | 效果 | 触发后 |
| --- | --- | --- | --- |
| 预抽牌 | 下回合抽牌时 | 额外抽 x 张牌 | 消失 |
| 费用预支 | 下回合获得费用时 | 额外获得 x 点费用 | 消失 |
| 疗愈 | 下回合角色行动阶段 | 恢复 x 点生命 | 不消失，每次触发层数减一，归零消失 |
| 预格挡 | 下回合开始时 | 获得 x 点格挡 | 消失 |

### 改动清单
1. `编辑器/buff创建.xlsx` 新增 4 行并运行 `sync_tables.py` 同步，buff 共 7 个：
   - 预抽牌 / 费用预支 / 预格挡：类型“层数增益”，基础持续 1，触发后消失；
   - 疗愈：类型“层数增益”，基础持续 10（= 最大层数，保证层数耗尽前不被持续时间移除），触发后不消失。
2. `scripts/battle/battle_manager.gd`：
   - 新增触发时机结算：下回合开始时（预格挡）、下回合抽牌时（预抽牌）、下回合获得费用时（费用预支）、下回合角色行动阶段（疗愈）；
   - 战斗数据分类：`lose_hp`（失去生命，无来源、无视格挡、不受力量/易伤影响）与 `take_damage`（受到伤害，有来源，受力量/虚弱/易伤影响，可被格挡抵挡）；中毒改为失去生命；
   - 新增 `heal_unit`（疗愈恢复，不超过最大生命）。
3. `scripts/battle/battle_unit.gd`：删除 `shield` 字段，护盾/格挡统一为 `block_value`（格挡）。
4. `scripts/battle/turn_system.gd`、`battle_map.gd`：轮次开始清空格挡相关注释同步更新。
5. 逻辑链注释：`attack_effect.gd` / `defense_effect.gd` / `buff_effect.gd` 更新数据分类与格挡统一说明。

### 设计说明
- “下回合”按“目标下一次行动”解释：若目标本轮尚未行动，buff 在其同轮下一次行动时触发；否则下轮触发。
- 格挡（原护盾 + 格挡合并）在轮次开始时清空；预格挡在目标回合开始（轮次清空之后）触发，格挡可持续到本轮结束。
- 疗愈基础持续设为最大层数 10，实际移除由“层数减到 0”控制，避免提前到期。

### 验证
- Godot 无头诊断：BuffDB 解析 7 个 buff；模拟触发验证 预抽牌+2 抽 7 张 / 费用预支+3 得 6 费 / 疗愈 3 层恢复 3 点且层数减一 / 预格挡+4 得 4 格挡；中毒（失去生命）无视格挡；受到伤害被格挡抵消且易伤生效。`BUFF_DIAG_OK`。
