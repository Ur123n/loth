# 战斗测试 Demo 说明

启动：双击 `启动战斗测试demo.bat`（或 `C:\1\Godot_v4.7.1-stable_win64_console.exe --path "C:\游戏" res://demo/BattleTestDemo.tscn`）。

## 战役流程（固定 6 场）

1. 启动后直接进入第一场战斗（随机地图 + 按流程配置的敌怪）。
2. 战斗结束弹出结算界面：拾取战利品（体积入背包）、经验升级（自由属性点）。
3. 结算后进入**卡牌奖励**：每名角色独立掷骰掉落，命中则从“通用库 + 该角色道途卡”随机展示 3 张，三选一加入技能库，或跳过；Boss 战每名角色可三选一两次。
4. 回修整营地，靠近中央光点进入下一场。

固定流程：**小战斗 ×2 → 精英战 ×1 → 小战斗 ×2 → Boss 战 ×1**（共 6 场）。

- 小战斗：1 支普通小队（3~4 只普通怪）
- 精英战：1 支精英小队（含精英）
- Boss 战：1 支 Boss 小队（含 Boss）

通关后靠近光点可重新开始（重置角色与战斗进度）。
Demo 使用独立存档 `user://demo_save.json`，不影响正式游戏存档。

## 控制

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| ↑ / ↓ | 切换小队角色 |
| Tab | 角色面板（升级获得的属性点在此分配；技能库/卡组管理） |
| B | 背包（滚轮翻页） |
| Esc | 关闭面板/弹窗 |

## 道途（四人四道途，各 3~4 张专属初始牌，开局加入技能库与卡组）

| 角色 | 道途 | 基础被动 | 专属初始牌 |
| --- | --- | --- | --- |
| 艾莉丝 | 梦魇行者 | 沉梦：回合开始获得2格挡（等级每5级+1） | 梦魇撕咬、沉梦之拥、幻梦利爪 |
| 鲍德温 | 孢子卫士 | 孢子怪力：移动力2 / 伤害1.25倍 / 自带1护甲 | 巨剑挥砍、孢子硬化、重甲横扫 |
| 迪马斯 | 侠盗 | 先下手为强：首回合额外抽2张、移动力+1 | 双枪连射、掠夺本能、弹雨、顺手牵羊 |
| 卡莎 | 解剖学者 | 药理精通：对中毒敌人额外伤害（等级每5级+1） | 腐蚀试剂、兴奋药剂、手术刀 |

初始卡组由道途初始牌 + 打击/防御补齐到 20 张（GDD 第 11 节）。

## 卡牌掉落表（content/cards/card_drops.json，Demo 专用）

| 难度 | 掉落概率 | 三选一次数 |
| --- | --- | --- |
| 普通 | 50% | 1 |
| 精英 | 80% | 1 |
| Boss | 100% | 2 |

每名角色独立掷骰；候选卡 = 通用库（不含基础 打击/防御）+ 该角色道途专属卡，随机 3 张不重复。

## 敌怪构成（敌方小队表）

每场战斗从「敌怪小队表」中按强度随机抽取一支 3~4 只的配合小队：
- 普通战：普通小队（骷髅巡逻队 / 亡者围猎队 / 孢子侵袭队 / 蛛群奔袭队 / 猪人劫掠队 / 亡者尸潮队）
- 精英战：精英小队（孢子巨兽队 / 蛛巢绞杀队 / 母蛛巢穴队 / 血裔猎杀队 / 灵教净坛队 / 血裔狂暴队）
- Boss 战：Boss 小队（终焉惧像战团 / 牧首影卫 / 深渊血宴 / 惧像蛛群）

数据由 Excel 驱动（编辑器/敌怪创建.xlsx、敌怪小队创建.xlsx、道途创建.xlsx），修改后运行 同步表格.bat；卡牌用卡牌编辑器创建。
